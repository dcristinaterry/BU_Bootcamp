## module2/ : Programming fundamentals (variables, control flow, methods, files)
### Project: Grade Analyzer
Reads student scores from a text file and generates a grade analysis report.

Features:
- Reads scores using `BufferedReader`
- Handles invalid and blank input
- Calculates average, highest, and lowest scores
- Calculates grade distribution
- Writes results to a report using `BufferedWriter`
- Accepts an input filename as a command-line argument
- module3/ : Data structures and object-oriented basics

## module3/ : Data structures and object-oriented basics
### Project: Contact Manager
A simple contact management application using Java collections.
Features:
- Stores contacts using a `HashMap`
- Looks up contacts by name
- Handles contacts that are not found
- Sorts contacts alphabetically
- Uses a custom `Contact` class
- Overrides `toString()` for formatted output
